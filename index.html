relayhubthe web, from somewhere else

This is a server, not a static site — it has to be deployed.

Relay Hub is a Node.js proxy. It fetches pages on the server and rewrites them before sending them to your browser. That work can only happen somewhere that can run Node. GitHub Pages cannot run Node — it only serves static files — so this URL shows the project's README instead of the app.

Why you're seeing a README

GitHub Pages was enabled on this repository, serving statically from main. With no index.html in the repo, Pages rendered README.md as a web page — including its screenshots. The app itself never ran, because nothing can run on Pages.

Deploy it in one click

R Render — recommended Reads render.yaml, free tier, HTTPS included. Set RELAY_PASS when prompted. R Railway Deploy from the repo using railway.json. Usage-based, no free tier. F Fly.io Uses fly.toml and the Dockerfile. Run fly launch --copy-config locally for full control.

Or run it yourself

# no dependencies — Node 18+ is all you need
git clone https://github.com/socks275/Relay-hub.git
cd Relay-hub
node server.js
# → http://localhost:3000

# or with Docker
docker run -p 3000:3000 relay-hub
Read this before deploying publicly. A public proxy fetches any URL on request, on your server's IP and your bill. Set RELAY_PASS to require a password, and keep TLS in front (Render, Railway and Fly all do this for you).
